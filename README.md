# GridSnap — Update-Feed

Dieses Repository enthält ausschließlich die Update-Beschreibung
(`appcast.xml`) für die macOS-App **GridSnap**. Kein Quellcode.

Die Programmdateien selbst hängen als Anhang an den
[Releases](../../releases) dieses Repositories. Jede Datei ist mit dem
privaten EdDSA-Schlüssel des Entwicklers signiert; GridSnap installiert
ausschließlich Fassungen, deren Signatur zum eingebauten öffentlichen
Schlüssel passt. Eine ausgetauschte Datei wird abgelehnt.

Die App selbst wird über einen Lizenzschlüssel freigeschaltet.
